# ﻿Simple Calculator

# Overview
This is a command-line calculator application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

# Features
Add two numbers
Subtract two numbers
Multiply two numbers
Divide two numbers
Continuous calculations until user chooses to exit

# Usage
Command-line Interface (CLI)
Run the calculator application:

After setting up, run the application using:
bash
Copy code
python main.py
Application Functionality:

The application will present a menu with the following options:
Add
Subtract
Multiply
Divide
Exit
