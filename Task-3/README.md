# Quiz Game

# Overview
The Simple Quiz Game is a command-line application that presents multiple-choice questions to the user. The player selects answers, and the game tracks the score and provides feedback at the end.

Features
Multiple-choice questions with possible answers.
Tracks user’s score.
Provides feedback at the end of the quiz.
User-friendly command-line interface.

# Usage
Command-line Interface (CLI)
Run the Quiz Game:

After setting up, you can run the quiz game using the following command:
bash
Copy code
python quiz_game.py
Game Flow:

The game will present a series of multiple-choice questions.
For each question, you will need to choose the correct answer by typing the corresponding number.
At the end of the quiz, your score will be displayed, and feedback will be provided.
